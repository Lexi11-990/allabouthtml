HTML5 and Semantic Elements

HTML5 is the modern version of HTML and introduced new features and elements that help developers create more organized and meaningful webpages.

What Is HTML5?

HTML5 provides elements and features that allow webpages to include different types of content while giving the content a clearer structure.

Semantic HTML

Semantic HTML uses elements that describe the purpose of the content they contain. These elements can make webpages easier for people and browsers to understand.

Examples of Semantic Elements

  • <header> - introductory content for a page or section
  • <nav> - navigation links
  • <main> - the main content of a webpage
  • <section> - a section of related content
  • <article> - independent content
  • <footer> - information at the bottom of a page

Why Semantic HTML Matters

Semantic elements help organize webpages and can improve accessibility, readability, and the overall structure of a website.
